# ouroboros-consensus-tools

Tools related to the [Consensus](https://github.com/IntersectMBO/ouroboros-consensus/) component of Cardano.

- [beacon](beacon/README.md): a tool used to compare performance of two Consensus versions.
- [check-leios-analysis](check-leios-analysis/README.md): a manual test that checks the Leios analyses of `db-analyser` against a real Leios chain.
